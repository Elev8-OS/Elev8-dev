# SaaS Copywriting Skill

This skill guides the creation of high-converting, crystal-clear, and compelling copy across the entire software customer lifecycle—from initial visitor landing pages to product onboarding and retention.

---

## 1. Core Operating Principles

1. **Clarity Over Cleverness**:
   - If a prospect doesn't understand what the software does within 5 seconds, clever puns won't save the conversion.
   - Avoid buzzword salad (*"synergistic AI-driven paradigm"* → *"automates your weekly billing in 2 clicks"*).

2. **Customer-Centric (You > We)**:
   - Talk about the user's world, problems, and workflow, not your company's pedigree.
   - Ratio rule: Aim for 3:1 ratio of "You/Your" to "We/Our".

3. **Features Tell, Benefits Sell, Outcomes Close**:
   - *Feature*: Automated calendar synchronization.
   - *Benefit*: Never double-book or manually update iCal links again.
   - *Outcome*: Save 6 hours every week and eliminate awkward guest cancellations.

4. **Friction Reduction & Risk Reversal**:
   - Accompany major commitment asks (Sign Up, Buy, Upgrade) with risk reducers: *"14-day free trial · No credit card required · Setup in 3 minutes"*.

5. **Scannability First**:
   - Visitors skim. Use punchy subheadings, bold anchor phrases, 1–3 sentence paragraphs, bullet points, and high-contrast callout boxes.

## 2. Standard Copywriting Workflow

When the user requests SaaS copy (e.g. landing page, pricing page, feature section, onboarding modal):

```
1. Discovery & Context Gathering
   ├── Target Audience (ICP) & Job-to-Be-Done (JTBD)
   ├── Primary Pain Point vs Desired Future State
   └── Competitive Alternative (Spreadsheets, manual labor, legacy tool)

2. Positioning & Value Proposition Architecture
   ├── Headline (Hook + Core Value)
   ├── Subheadline (Who, How, Proof/Mechanism)
   └── Primary CTA + Trust Anchor

3. Section Drafting via Proven Frameworks
   ├── Problem-Agitate-Solve (PAS)
   ├── Before-After-Bridge (BAB)
   └── Feature-Advantage-Benefit (FAB)

4. Polish & Audit
   ├── Strip fluff & jargon
   ├── Tighten active verbs
   └── Check scannability and microcopy
```

## 4. SaaS Copy Quality Checklist

Before finalizing any copy output, run this quick 6-point check:

1. [ ] **The "So What?" Test**: Does every feature claim answer why the user should care?
2. [ ] **The Competitor Swapping Test**: If you replace your product name with a competitor's, does the copy still sound generic? If yes, add specific mechanics or metrics.
3. [ ] **Actionable Verbs**: Are headlines leading with active verbs (*Build, Automate, Track, Launch, Reclaim*) instead of passive nouns (*Solution, Optimization, Capabilities*)?
4. [ ] **Specificity**: Are claims backed by numbers, time saved, or concrete artifacts (*"under 90 seconds"*, *"syncs with 12+ OTAs"*, *"0 lines of code"*)?
5. [ ] **Objection Preemption**: Did you address the top doubt (e.g. implementation time, data security, migration pain, pricing surprise)?
6. [ ] **Clear Next Step**: Is there one unambiguous primary action for the user to take?
