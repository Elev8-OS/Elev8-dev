Confidence: 0.72

Confidence: 0.72

- User-facing UI copy must be plain, human-readable language — never technical abbreviations (e.g. "WoW"/"YoY" → "vs last week"/"vs last year") and never raw variable names in charts/legends (e.g. `averageScore`/`fiveStarRate` → "This year"/"Last year").
