# Website Builder

- `/website-builder/create` is a 5-step wizard for a new site (Template, Settings, Property, Reviews, Preview). With `?edit=<id>` it renders `WebsiteEditor.vue` instead.
- **Edit layout** (`components/website-builder/WebsiteEditor.vue`): header (name, listing count, status icon, URL, Re-render, Unpublish, Save changes / Publish), left section nav, one section at a time. AI Generate (default) is a chat (`WebsiteAiChat.vue`: greeting + suggestion chips, thread, composer, built on the `ui/message`, `ui/conversation` and `ui/prompt-input` primitives) beside a live `WebsitePreviewFrame.vue`, split by a draggable `ResizablePanelGroup` (chat 25-75%, size remembered per orientation via `auto-save-id`; stacked vertically below `lg`). Mock engine: it only changes the headline (`settings.description`), brand color and font, and says so for anything else; nothing is sent anywhere. Site Settings, Manage Listings and Reviews embed `SettingsStep`, `PropertyStep` and `ReviewStep` with `embedded` (no Back / Next). The chat header has a History popover (no separate Version History section): the current version plus one entry per ElevAI change this session, each restorable; the chat stays mounted (`v-show`) while another section is open. Analytics reads the website record; Hero Media, Blog, Surroundings, SEO and Cookie & Legal are empty states for now.
- Saving goes through `useWebsiteSave().saveWebsite()`, shared with `PreviewStep`. It writes the Website and hands the site's booking rules to `useWebsiteChannel().saveSiteRules()` (see `channels.md`). A website stores `propertyIds`, not rooms, so the editor only requires one property.
- The editor does not run the Reviews step's own validity check; it saves the selection as it stands.
